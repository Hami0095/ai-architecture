# ArchAI staleness study: Scrapy 2.10.0 to 2.19.0

**Research question:** when code changes, does an evidence-linked, staleness-aware
architecture model (ArchAI) stop an LLM from acting on outdated structural claims,
compared with plain memory notes or a plain graph?

**Subject:** [Scrapy](https://github.com/scrapy/scrapy) (BSD-3-Clause), release tags
2.10.0 … 2.19.0. Only the `scrapy/` package is analyzed. Tags and their commit
hashes are pinned in `config.yaml`; Scrapy's code is never modified.

| Phase | Status | Report |
|---|---|---|
| 1. Ground truth and staleness detection (no LLM) | done | [phase1_report.md](phase1_report.md) |
| 2. Does the trust layer change LLM answers? | PENDING | — |

## Reproduce Phase 1

From the ArchAI repository root, with ArchAI installed (`pip install -e .`):

```bash
python experiments/scrapy_staleness/phase1.py            # clone, extract, build, evaluate, report
python experiments/scrapy_staleness/phase1.py --report   # rebuild the report from saved results
python -m pytest tests/test_staleness.py                  # verifier unit tests
```

The script is resumable. It:

1. clones Scrapy into `repos/scrapy` (gitignored), checks every tag against the pinned
   commit, and extracts each tag's `scrapy/` package into `repos/<tag>/`;
2. builds the ArchAI graph per tag → `graphs/<tag>.json` (graph + build metadata),
   and an OKF bundle → `bundles/<tag>/` (gitignored; regenerated by the script);
3. computes the drift matrix for every ordered tag pair → `results/phase1/drift_matrix.json`;
4. runs the staleness verifier (`ai_architect/standards/staleness.py`) for every older
   graph against every newer tag, scores it against the ground truth, and runs the
   window sensitivity analysis and timing comparison;
5. writes `phase1_report.md` and `plots/*.svg`.

No LLM and no network access are used, except `git clone` and `git fetch` for Scrapy.

## Definitions

- **Edge:** a unique (source, target) pair of `scrapy.*` modules linked by a
  module-scope import. (Function-level, type-checking and dynamic imports are stored
  in the graphs but are not ground-truth edges.)
- **Module:** a `scrapy.*` module name (file path mapped to a dotted name).
- **Moves:** git rename detection (`git diff --find-renames`, default 50% similarity)
  between the two tags. They are reported as moves, and scored as stale facts.
- **Verifier labels:** VERIFIED, STALE and UNVERIFIABLE; see the docstring of
  `ai_architect/standards/staleness.py`. The search window is the cited line ±5,
  fixed before the run.
