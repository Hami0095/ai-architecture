# ArchAI staleness study: Scrapy 2.10.0 to 2.19.0

**Research question:** when code changes, does an evidence-linked, staleness-aware
architecture model (ArchAI) stop an LLM from acting on outdated structural claims,
compared with plain memory notes or a plain graph?

**Subject:** [Scrapy](https://github.com/scrapy/scrapy) (BSD-3-Clause), release tags
2.10.0 … 2.19.0. Only the `scrapy/` package is analyzed. Tags and their commit
hashes are pinned in `config.yaml`; Scrapy's code is never modified.

| Phase | Status | Report |
|---|---|---|
| 1. Ground truth and staleness detection (no LLM) | done | [phase1_report.md](phase1_report.md) |
| 2. Does the trust layer change LLM answers? | harness and mock run done; smoke test and model runs PENDING | — |

## Phase 2 harness

```bash
python experiments/scrapy_staleness/phase2.py questions                # questions/<tag>.json (seed 42)
python experiments/scrapy_staleness/phase2.py samples                  # questions/sample_prompts.md
python experiments/scrapy_staleness/phase2.py run --model mock         # results/mock/raw.jsonl (resumable)
python experiments/scrapy_staleness/phase2.py analyze --model mock     # results/mock/analysis.json + SVG plots
python -m pytest experiments/scrapy_staleness/test_phase2.py           # harness tests
```

- **Questions:** Q1–Q4, generated from the ground-truth graphs only, 40 per target
  tag, half `changed` and half `unchanged` relative to 2.10.0, split equally across
  templates and subtypes. The changed stratum includes answers that became yes
  (`new_edge`, `gained_imports`, `new_module`). For Q4, `unchanged` means cycle
  membership is unchanged, and a named cycle must exist at the target tag.
- **Conditions:** A (no context), B (AGENTS.md-style notes from the 2.10.0 graph),
  C (relevant 2.10.0 facts), D-strict / D-reanchored (the same facts with evidence,
  verifier labels, coverage labels and rules), E (relevant facts from the target graph,
  as a ceiling). Every condition gets the same system prompt and question.
- **Models:** `mock` is a deterministic rule-based reader of the context. It tests the
  harness and is not a result. Real models run only through a local Ollama server
  (`ollama:<name>`), with temperature 0, seed 42 and 3 runs per prompt.

## Reproduce Phase 1

From the ArchAI repository root, with ArchAI installed (`pip install -e .`):

```bash
python experiments/scrapy_staleness/phase1.py            # clone, extract, build, evaluate, report
python experiments/scrapy_staleness/independent_gt.py    # grimp ground truth (pip install grimp)
python experiments/scrapy_staleness/phase1.py --report   # rebuild the report from saved results
python -m pytest tests/test_staleness.py                  # verifier unit tests
```

The script is resumable. It:

1. clones Scrapy into `repos/scrapy` (gitignored), checks every tag against the pinned
   commit, and extracts each tag's `scrapy/` package into `repos/<tag>/`;
2. builds the ArchAI graph per tag → `graphs/<tag>.json` (graph + build metadata),
   and an OKF bundle → `bundles/<tag>/` (gitignored; regenerated by the script);
3. computes the drift matrix for every ordered tag pair → `results/phase1/drift_matrix.json`;
4. runs the staleness verifier (`ai_architect/standards/staleness.py`) for every older
   graph against every newer tag, scores it against the ground truth, and runs the
   window sensitivity analysis and timing comparison;
5. writes `phase1_report.md` and `plots/*.svg`.

No LLM and no network access are used, except `git clone` and `git fetch` for Scrapy.

## Definitions

- **Edge:** a unique (source, target) pair of `scrapy.*` modules linked by a
  module-scope import. (Function-level, type-checking and dynamic imports are stored
  in the graphs but are not ground-truth edges.)
- **Module:** a `scrapy.*` module name (file path mapped to a dotted name).
- **Moves:** git rename detection (`git diff --find-renames`, default 50% similarity)
  between the two tags. They are reported as moves, and scored as stale facts.
- **Verifier labels:** VERIFIED, STALE and UNVERIFIABLE; see the docstring of
  `ai_architect/standards/staleness.py`. The search window is the cited line ±5,
  fixed before the run.
- **Re-anchoring** (D-reanchored, added after the Phase 1 results and before any LLM
  run): a STALE edge fact becomes VERIFIED only if the same source file still contains
  an import in the same scope class (module / function / type_checking / dynamic) that
  resolves to the same target. The new file:line is recorded.
- **Coverage label** per cited file: COMPLETE if its sha256 is unchanged since the graph
  was built, POSSIBLY_INCOMPLETE otherwise. A missing fact in a POSSIBLY_INCOMPLETE file
  is not evidence that the import does not exist.
- **Git-restricted verification:** re-reads only files `git diff` reports as changed,
  and carries the rest over unread. It is measured for time and labels, but not used in
  any condition.
- **Independent ground truth:** `independent_gt.py` rebuilds 2.10.0, 2.16.0 and 2.19.0
  with [grimp](https://github.com/seddonym/grimp), which shares no code with ArchAI.
